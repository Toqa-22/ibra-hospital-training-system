# نظام تسجيل وإدارة المتدربين
### قسم التدريب والتطوير المهني

نظام داخلي لتسجيل المتدربين وإدارة سجلاتهم، مبني بالكامل باستخدام HTML5 وCSS3 وJavaScript (ES6) مع قاعدة بيانات Supabase — بدون أي إطار عمل (Framework).

---

## المتطلبات

- حساب [Supabase](https://supabase.com) (مجاني).
- أي خادم تطوير محلي بسيط، مثل إضافة **Live Server** في VS Code.
- متصفح حديث.

---

## خطوات الإعداد

### 1. إنشاء مشروع Supabase

1. أنشئ مشروعاً جديداً في [supabase.com](https://supabase.com).
2. من قائمة **SQL Editor**، نفّذ الملفين بالترتيب:
   - `sql/schema.sql` — لإنشاء جدول `students`.
   - `sql/policies.sql` — لتفعيل سياسات أمان الصفوف (RLS).

### 2. ربط المشروع بالواجهة الأمامية

المكان الوحيد الذي تضع فيه بيانات الاتصال هو ملف **`js/config.js`** (هذا الملف مستثنى من Git تلقائياً عبر `.gitignore` — لا يُرفع أبداً لمستودعك).

1. من **Project Settings → API** في Supabase انسخ:
   - `Project URL`
   - `anon public key`
2. افتح `js/config.js` وضع القيمتين مكان القيم الافتراضية:
   ```js
   window.APP_CONFIG = {
     SUPABASE_URL: "https://YOUR-PROJECT-REF.supabase.co",
     SUPABASE_ANON_KEY: "YOUR-PUBLIC-ANON-KEY",
   };
   ```

لا حاجة لتعديل أي ملف آخر — لا `js/supabase.js` ولا أي مكان غيره. إن أردت مشاركة المشروع أو رفعه إلى Git، استخدم `js/config.example.js` كقالب فارغ يُرفع بدلاً من `config.js`.

⚠️ **لا تستخدم أبداً** مفتاح `service_role` هنا — استخدم `anon key` فقط.

### 3. التشغيل محلياً

1. افتح مجلد المشروع في VS Code.
2. انقر بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server**.
3. ستفتح صفحة **تسجيل المتدربين** تلقائياً.
4. للوصول للوحة الإدارة، انتقل إلى `dashboard.html` من شريط التنقل العلوي.

## المزايا الرئيسية

- **تسجيل المتدربين**: نموذج تسجيل عربي بالكامل (RTL) مع تحقق فوري من صحة البيانات، وحساب تلقائي لمدة التدريب.
- **اختيار الأقسام حسب الفئة**: يختار الموظف الفئة الرئيسية أولاً (الفئات الطبية / الفئات الطبية المساعدة / الأقسام الإدارية / أقسام الهندسة والصيانة)، ثم يختار قسماً واحداً أو أكثر من نفس الفئة أو من فئات مختلفة. **كل قسم مختار له فترة تدريب مستقلة** (تاريخ بداية ونهاية خاصان به)، وليس فترة موحّدة لكل الأقسام. عند التسجيل، يُنشأ سجل مستقل في قاعدة البيانات لكل قسم مختار، بنفس بيانات الطالب، وبفترة التدريب الخاصة بذلك القسم فقط.
- **بطاقات الأقسام**: تُعرض ديناميكياً من بيانات Supabase، وتظهر فقط الأقسام التي تحتوي على متدرب واحد على الأقل، مرتبة تنازلياً حسب العدد.
- **جدول المتدربين**: بحث وفلترة فورية (بما في ذلك تصفية حسب الفئة الرئيسية بالإضافة إلى القسم)، فرز حسب أي عمود، ترقيم صفحات، ورأس ثابت (Sticky Header).
- **تصفية حسب الفئة**: شريط شرائح فوق بطاقات الأقسام + قائمة منسدلة في لوحة الفلاتر، لعرض بطاقات الأقسام وصفوف الجدول الخاصة بفئة رئيسية واحدة فقط (الفئات الطبية / الفئات الطبية المساعدة / الأقسام الإدارية / أقسام الهندسة والصيانة).
- **تقرير كل متدرب**: زر "⬇ تقرير" في كل صف بجدول المتدربين يفتح تقريراً قابلاً للطباعة أو الحفظ كملف PDF (عبر خاصية الطباعة بالمتصفح)، يتضمن شعار المستشفى واسم "مستشفى إبراء" أعلى الصفحة توسيطاً، ثم بيانات الطالب، ثم جدولاً بكل الأقسام التي سُجّل فيها مع فترة التدريب الخاصة بكل قسم وحالته.
- **إدارة التكرار**: تجميع بصري للمتدرب الذي يسجّل أكثر من مرة (نفس الاسم + نفس الهاتف) دون حذف أي سجل، مع صفوف قابلة للتوسيع.
- **حالة التدريب**: حساب تلقائي لحالة كل سجل (قيد التدريب / لم يبدأ / انتهى) بناءً على تاريخ اليوم.
- **تصدير Excel**: تصدير جميع السجلات إلى ملف Excel منسق باستخدام SheetJS.
- **الأمان**: سياسات RLS، استخدام Anon Key فقط، تعقيم كل المخرجات (Escape HTML) قبل العرض، ومنع النقر المتكرر أثناء الحفظ.
- **تجربة المستخدم**: تنبيهات Toast مخصصة، نافذة تأكيد مخصصة (بدون `alert()`/`confirm()`)، حالات تحميل هيكلية (Skeleton)، وحالات فارغة احترافية.
